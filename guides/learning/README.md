# Learning guides

The [Qwen playground guide](qwen/QWEN_PLAYGROUND_GUIDE.md) has a
[printable PDF](qwen/QWEN_PLAYGROUND_GUIDE.pdf). The
[token representation walkthrough](qwen/TOKEN_REPRESENTATION.md) links its
recorded interactive example. The original local verification observations are
in [VERIFICATION.json](qwen/VERIFICATION.json).

Regenerate the PDF with `./.venv/bin/python tools/build-guide.py` from the
repository root. The model runtime and experiment instructions remain in
[experiments/qwen](../../experiments/qwen/README.md).
