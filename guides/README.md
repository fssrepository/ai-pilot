# Documentation

| Directory | Content |
| --- | --- |
| [development](development/README.md) | Research plans and project records |
| [learning](learning/README.md) | Qwen playground guide, token walkthrough and recorded example |
| [publication](publication/README.md) | Published research reports and PDFs |

Each document has one canonical location. A PDF stays beside its editable
Markdown source; figures and cover metadata stay with the report they support.
Generated runtime data remains in the ignored `artifacts/` directory.

The experiment-specific instructions are in [experiments](../experiments/).
Historical verification manifests under experiment `examples/` retain the paths
and hashes recorded when those runs were made. They are snapshots, not current
documentation links.
