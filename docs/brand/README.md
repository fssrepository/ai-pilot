# AI Pilot document style

AI Pilot is an independent research project. Covers use the project name as
plain text, with no logo or affiliation with another portfolio. The existing
ReportLab builder owns layout; per-report JSON files provide titles and metadata.

Document IDs use the AIP prefix. Historical verification manifests preserve
old source/artifact hashes; current branding and relocation checks are recorded
in the v2 verification manifest. Model measurements were not changed by renaming.
