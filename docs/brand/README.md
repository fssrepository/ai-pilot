# MyScoutee document branding

`myscoutee-m.png` is the unchanged MyScoutee M mark from
`myscoutee-backend/frontend/src/assets/logo/heart.png`. It is the same asset used
with the `yScoutee` wordmark on the official manuals' cover pages.

The cover layout follows `myscoutee-backend/guides/manuals/manuals.css` and its
`myscoutee-microservices-guide-en.html`: brand header, category/title/lead block,
blue vertical rule and two-column document metadata. The local report uses the
existing `tools/build-guide.py` renderer, extended with optional cover metadata,
so generating this report does not rebuild or mutate another project's manuals.
The asset is included here to keep this repository's PDF build self-contained.
